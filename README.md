# Claudia's Little Corner

A bespoke Czech/English friendship surprise made with React and Vite.

## Run locally

1. Install Node.js LTS.
2. Extract this folder.
3. Open PowerShell in the project folder.
4. Run:

```powershell
npm.cmd install
npm.cmd run dev
```

5. Open http://localhost:5173/

## Included

- Funny mood-changing cat reaction GIFs (internet connection required).
- Czech-first / English toggle.
- Responsive two-column desktop layout and stacked mobile layout.
- One-shot heart blast only when the gift is opened. There are no ambient or always-on particles.
- Optional synthesized UI sound effects.
- Three concise, personal friendship chapters.
- Single-click gift interaction, keyboard-accessible buttons, and reduced-motion support.

Google Fonts are loaded online with system fallbacks. Cat GIFs are hosted on Tenor.
